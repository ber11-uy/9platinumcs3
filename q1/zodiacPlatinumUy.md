## Requirements

### A. Ask the User to Enter a Year of Birth

The program asks the user to enter their year of birth. The baseline year is 1900.

### B. Validate User Input

The program validates the user's input and checks that the year is not earlier than 1900.

### C. Invalid Year

If the user enters a year earlier than 1900, the program displays an appropriate message and does not continue with the Zodiac calculation.

**Example:**

```text
Enter your birth year: 1800
Invalid Year, it should not be earlier than 1900
